The ASSIST Research Lab is directed by Dr. Siddhartha Bhattacharyya. The research focuses on the application of theories to practice. 02 / CORE DOMAINS
RESEARCH PILLARS

ASSIST (Assured Safety, Security and Intent with Systematic Tactics) Research Lab focuses on the design and development of assurance frameworks for mission-critical, safety-critical, and security-critical systems. The assurance frameworks designed integrate tools based on theories of computation, formal methods, model-based engineering, architecture analysis, and software/systems engineering principles. This results in performing a rigorous analysis of systems or system of systems to assure the correctness in the behavior of systems.

DOMAIN 01

Cognitive Intelligence & Intent Recognition

Inferring user, system, and adversary intent in multi-agent environments using probabilistic models, test-time prompt refinement, and self-supervised cognitive frameworks.

Key: Intent AI ALINA Core
DOMAIN 02

Assured Cybersecurity & Safety Guards

Formal methods, assume-guarantee reasoning (AGR), mathematical safety contracts, and real-time execution guards preventing neural network policy violations.

Key: MBSE & Formal FLAIR Verification
DOMAIN 03

Autonomous Avionics & Swarm Systems

Computer vision for taxiway/runway navigation under severe distribution shifts (AssistTaxi benchmark), flight safety assurance, and cooperative autonomous swarms.

Key: NASA & DARPA AssistTaxi-v2
DOMAIN 04

Complex Systems Biology & Network Analysis

Deep learning assurance for Left Ventricular Assist Devices (LVADNet3D), medical image classification, nephrology representations (NORA), and biological network dynamics.

Key: Health AI LVADNet3D

OPEN SOURCE TOOLS
FRAMEWORK Python / C++

ALINA (Assurance Language for Intent Analytics)

Domain-specific language and execution monitor for checking multi-agent intent specifications in real-time cyber-physical operations under noisy telemetry.

  • • Temporal logic intent semantics
  • • Low-latency runtime verification engine
  • • Integration with ROS 2 and PX4 autopilot systems
LICENSE: MIT VER: 2.1.0
TOOLKIT OCaml / Rust

FLAIR (Formal Logic AI Verification Framework)

Formal verification suite implementing assume-guarantee contract reasoning for neural network policies in safety-critical autonomous systems.

  • • SMT solver interface (Z3 / CVC5)
  • • Contract-based safety assertion checker
  • • Automated counterexample generator
LICENSE: BSD-3 VER: 1.4.2
DATASET & BENCHMARK PyTorch / Data

AssistTaxi (Airport Surface Navigation Benchmark)

Scalable benchmark dataset collected under NASA grants featuring multi-weather, extreme glare, and lighting distribution shifts on airport taxiways and runways.

  • • 50,000+ high-resolution annotated frames
  • • Segmented taxi line & hold-short markings
  • • Out-of-distribution evaluation protocol
LICENSE: CC BY 4.0 DATASET v2.0
ARCHITECTURAL PLUGIN SysML / Java

MBSE-AGR (Assurance Guard Architecture Plugin)

Cameo/MagicDraw plugin integrating Assume-Guarantee Reasoning (AGR) contracts directly into Model-Based Systems Engineering (MBSE) workflows.

  • • SysML v2 contract profile support
  • • Automated architectural consistency checks
  • • Exportable safety case certificates
LICENSE: Apache 2.0 VER: 3.0.1
